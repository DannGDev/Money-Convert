<h1>📌 About the Project</h1>
<br>
<p><b>DannG-Dev Money Convert</b> is a browser-based currency conversion tool that allows users to convert values between different currencies quickly and easily. The project focuses on usability, clarity, and front-end fundamentals, demonstrating JavaScript logic, DOM manipulation, and UI updates without relying on external frameworks.</p>
<p>This application is part of my front-end development portfolio and showcases my ability to build interactive web tools using only core web technologies.</p>
<br>
<br>
<h1>🚀 Features</h1>
<ul>
  <li>✔ Convert between multiple currencies (USD, BRL, EUR, GBP, CAD, MXN, BTC, etc.)</li>
  <li>✔ Clean and intuitive user interface</li>
  <li>✔ Instant conversion results</li>
  <li>✔ Responsive layout for different screen sizes</li>
</ul>
